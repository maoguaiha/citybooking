# 🌱 greenfield 完整流水线（分支 A）

> 本文件夹是 **greenfield（从零新建）** 项目的 **自包含开发流水线**。把它整体交给 Agent，Agent 即可独立按节点循环开发，无需项目根目录的任何其他文件。
> 通用方法论（红线/模板/Git/角色）已内置在 `参考文件/`（本目录），本文件夹只写 **A 分支特有动作 + 流转**。

## 本分支流转图（Phase 1~5，按 PROJECT-FLOW 节点循环）

```
本 README（入口）──▶ 01-init(A0选型+占位符落地)
                        │
        ┌───────────────┴─────────────── 外层：PROJECT-FLOW 节点 1→N
        │                                │
        ▼ 每节点                          ▼
  02-spec(A1 PRD/A2定级/A3 Spec)
        ▼
  03-coding(A4编码/A5单测) ──▶ 节点测试门+验收确认 ──fail──▶ 停留 03-coding 改
        │                                           ▼ pass
        ▼                                      04-review(A6审查/A6.5验收/A7合并)
                                                  │ 核心节点 → 05-deploy(上线验证) → done
                                                  │ 普通节点 → done
                                                  │ 违规/验证失败 → 退回 03-coding
```

## 启动方式

**自主运行模式（推荐，交给 Agent 全自动跑）**：把本分支文件夹整体交给 Agent，给一句：
> 「读取 `执行材料/RUN.md`，严格按驱动循环自主执行，直到输出 `[SYS: 全部节点通过，流水线执行完毕]`。」

**手动 / 人工接力模式**：给 Agent：
> 「读取 `参考文件/README.md`，并严格执行其中的启动协议。」

Agent 启动后按顺序执行：
1. 读取本 `README.md`；
2. 读取 `../运行时/STATE.md`（若不存在 → 按 `../执行材料/01-init.md` 创建并初始化）；
3. 读取 `../运行时/PROJECT-FLOW.md`（若不存在 → 按 `../执行材料/02-spec.md` 创建节点表）；
4. 进入 `../执行材料/01-init.md` 开始第一个节点。

## 运行时工具（Agent 自动调用，你一般无需手动碰）

- `../运行时/gate.py`：在 `03-coding` 末尾**机械执行**本节点测试门（读 PROJECT-FLOW 的「机器可读测试门」块、真实跑命令、以退出码判定 PASS/FAIL）。
- `../运行时/validate-state.py`：长任务中途自检 `../运行时/STATE.md` 是否仍一致。
